# 📁 Power BI File Types: PBIX, PBIT and PBIP

Power BI supports different file types, each suited to a different purpose.

---

## Overview

| File type | Description |
|---|---|
| `.pbix` | Traditional Power BI Desktop file. Simple to use but hard to review in GitHub — it is one closed binary file. |
| `.pbit` | Power BI template. Useful when you want to share a reusable starting point. |
| `.pbip` | Power BI Project. Saves the report as a folder structure, making it easier to use with GitHub, VS Code and Fabric Git integration. |

---

## Simple Way to Remember

- **PBIX** = one report file
- **PBIT** = reusable report template
- **PBIP** = project folder for version control

---

## Which Should You Use?

| Situation | Recommended file type |
|---|---|
| Quick sharing with a colleague | `.pbix` or `.pbit` |
| Creating a reusable report template | `.pbit` |
| Working with GitHub or VS Code | `.pbip` |
| Connecting to a Fabric workspace | `.pbip` |
