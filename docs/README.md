# docs

This folder contains supporting documentation for the Power BI and Microsoft Fabric solution.

## What to Put Here

| File / Folder | Purpose |
|---|---|
| `architecture.png` | Architecture diagram referenced in main README |
| `screenshots/` | Report screenshots (organised by path or report name) |
| `data-flow.png` | Data flow diagram |
| `access-matrix.md` | Access control and security group mapping |
| `file-types.md` | Reference guide for Power BI file types (PBIX, PBIT, PBIP) |

## Architecture Diagram

Save your architecture diagram as `architecture.png` in this folder.
It will automatically render in the main README.

## Screenshots

Store report screenshots in `docs/screenshots/`. You can organise them by report name or by workflow path:

```
docs/
└── screenshots/
    ├── report-name/
    └── ...
```
