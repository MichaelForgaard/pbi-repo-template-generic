# Security Policy

If you discover a security vulnerability in this project, please follow the steps below to report it responsibly.

## Reporting a Vulnerability

- **Do not** open a public GitHub issue for security vulnerabilities.
- Contact the repository owner or maintainer directly via email or your organisation's preferred security reporting channel.
- Provide a clear description of the vulnerability, steps to reproduce, and potential impact.

## Response

The maintainer will acknowledge your report within 5 business days and work with you to resolve the issue promptly.
